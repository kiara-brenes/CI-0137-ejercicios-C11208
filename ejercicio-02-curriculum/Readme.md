## Cómo correrlo con Live Server

1. Abrir la carpeta en Visual Studio Code.
2. Si arriba sale la barra de Restricted Mode, darle a Manage y luego a Trust. 
3. Instalar la extensión Live Server desde la pestaña de extensiones.
4. Clic derecho sobre el archivo curriculum.html y elegir Open with Live Server.
5. Se abre en el navegador en `http://127.0.0.1:5500/curriculum.html`.
